# 머니나침반 v2: AI 맞춤형 재테크 코치

## 서비스 소개

머니나침반은 사용자의 월 소득, 지출, 저축액, 투자금, 부채, 재무 목표, 투자 성향을 바탕으로 재무 상태를 분석하고 재테크 방향을 제안하는 Streamlit 웹서비스입니다.

기존 규칙 기반 분석에 더해 다음 기능을 추가했습니다.

* 재테크 유형 진단
* 재무 스트레스 점수
* 목표 금액 기반 달성 기간 분석
* 이번 주 실천 미션
* AI 코칭 모드 선택

  * 재테크 코치
  * 소비습관 분석
  * 목표 달성 전략

Gemini API 키가 없어도 규칙 기반 분석은 정상 작동합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Gemini API 키 설정

Streamlit Cloud의 Secrets에 다음을 추가하면 AI 맞춤 코멘트가 활성화됩니다.

```toml
GEMINI\\\_API\\\_KEY = "본인의 Gemini API 키"
```

## 주의사항

본 서비스는 금융상품 가입이나 투자를 직접 권유하지 않습니다. 특정 은행명, 주식명, ETF명, 펀드명을 추천하지 않으며, 일반적인 재무관리 방향을 안내하는 참고용 도구입니다.
